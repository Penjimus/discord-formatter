Guide d'utilisation

Discord Formatter vous aide à préparer un message Discord bien mis en forme. Vous écrivez à gauche comme dans un traitement de texte ; à droite apparaît le texte prêt à coller dans Discord. Tout se passe dans votre navigateur : vos messages ne sont envoyés nulle part.

← Revenir à l'appli

1. Les deux panneaux

  • À gauche, l'éditeur : vous voyez le message presque comme dans Discord (gras, titres, listes, couleurs…).
  • À droite, le message Discord : le texte avec ses symboles (**, >, ```…). C'est lui que vous copiez.
  • Les deux côtés restent synchronisés : modifiez l'un, l'autre se met à jour. Vous pouvez aussi coller à droite un message Discord existant pour le retravailler à gauche.
  • Le bouton Copier, en haut à droite, copie le message complet ; collez-le ensuite dans Discord.

2. Mettre en forme le texte

  • Sélectionnez du texte, puis cliquez sur Gras, Italique, Souligné, Barré, Spoiler ou Code. Les styles se cumulent.
  • T1, T2, T3 : titres de trois tailles. Sous-texte : petit texte gris.
  • • Liste et 1. Liste : listes à puces ou numérotées. Tab et Maj+Tab changent le niveau (11 niveaux au plus).
  • Citation : la ligne est citée, avec la barre grise de Discord.
  • Un bouton grisé est une option impossible à cet endroit dans Discord ; survolez-le pour savoir pourquoi.

3. Blocs de code et couleurs

  • Bloc de code insère un bloc. Dans le champ Langage, tapez ou choisissez un langage (js, py…) : le bloc est coloré comme dans Discord.
  • Pour colorer vous-même du texte, laissez le langage vide (ou choisissez ansi), sélectionnez du texte dans le bloc et cliquez sur une couleur de Texte ou de Fond, ou sur Gras, Italique, Souligné, Barré de la ligne ANSI.
  • Les couleurs ne s'affichent que sur Discord ordinateur : sur téléphone, le texte apparaît sans couleur.

4. Mentions, émojis, horodatages

  • @ Utilisateur, @ Rôle, # Salon insèrent un modèle (par exemple <@ID_UTILISATEUR>). Vous pouvez aussi taper @ ou # à gauche. Un avertissement rappelle de remplacer le modèle par le vrai identifiant dans Discord.
  • Émoji ouvre le sélecteur ; la recherche marche en français et avec les codes anglais (:star:).
  • Horodatage : choisissez une date, une heure et un style ; chaque lecteur verra l'heure dans son propre fuseau. Cliquez sur un horodatage à gauche pour le modifier.
  • Les smileys :) :( :D :P ;) <3 :o, entourés d'espaces, sont changés en émojis par Discord. L'éditeur les montre donc déjà en émoji (🙂 🙁 😄 😛 😉 ❤️ 😮).

5. Liens

  • 🔗 Lien : sélectionnez un texte, cliquez sur le bouton et saisissez l'adresse. Le texte devient cliquable dans Discord, l'adresse reste cachée ([texte](adresse)). Sans sélection, la fenêtre demande aussi le texte.
  • Adresses permises : https://, http://, mailto:, tel:, discord://. Les autres (sans https://, www., ftp://…) ne sont pas cliquables dans Discord : l'appli les refuse. Un espace dans l'adresse est écrit %20.
  • Sans aperçu : cochez la case pour que Discord n'affiche pas de carte sous le message (l'adresse est alors écrite entre < >).
  • Passez la souris sur un lien à gauche : une bulle montre son adresse, avec Modifier (adresse, aperçu, retirer le lien) et Ouvrir (nouvel onglet). Le texte du lien se modifie directement, avec tous les styles.
  • Un émoji, une mention ou un [ seul ne peuvent pas être dans le texte d'un lien : s'il y en a un, il sort du lien, qui est coupé en deux morceaux de même adresse. Un horodatage, lui, est permis.

6. Le compteur

  • Sous le panneau de droite, le compteur indique la longueur du message et ce qu'il reste. Les boutons 2000 et 4000 choisissent la limite (4000 avec Nitro).
  • Au-delà de la limite, la barre devient rouge, mais rien n'est coupé : vous continuez à écrire librement.
  • Message trop long : un cadre par message apparaît sous le panneau de droite, dans l'ordre d'envoi, chacun avec son compteur et son bouton Copier. Le texte de droite, lui, ne change pas. Les styles, citations, blocs de code et couleurs coupés sont refermés puis rouverts, pour que chaque message s'affiche bien seul.
  • Pour gagner de la place, les cadres sont réduits à leur titre. Cliquez sur le titre d'un message pour le dérouler : le message complet se réduit alors en haut. Cliquez sur Message complet pour y revenir. Le bouton Copier marche même quand le cadre est réduit.
  • Un message copié reste marqué ✓ Copié jusqu'à la prochaine modification du texte : vous savez où vous en êtes. Un nouveau clic le copie à nouveau.
  • Si un message contient une mention à compléter (<@ID_UTILISATEUR>…), l'avertissement apparaît aussi dans son cadre : vous savez dans quel message la corriger.
  • Le compte suit celui de Discord : un émoji compte souvent pour 2, un drapeau pour 4, et les symboles de mise en forme comptent aussi.

7. L'aperçu façon Discord

  • Sous les deux panneaux, l'aperçu montre votre message comme Discord l'affichera sur ordinateur, en thème sombre, avec le nom « Vous » et l'heure. Il se met à jour pendant que vous écrivez. Faites défiler la page pour le voir en entier.
  • Il sert seulement à regarder : il ne change rien à votre texte. Les spoilers y sont cachés, un clic les révèle ; les liens s'ouvrent dans un nouvel onglet.
  • Message trop long : l'aperçu montre les messages découpés l'un sous l'autre, comme envoyés à la suite. En survolant un message, son heure apparaît à gauche.
  • Le bouton Masquer l'aperçu rend toute la hauteur aux panneaux ; Afficher l'aperçu le fait revenir.
  • Les teintes, tailles et polices sont proches de celles de Discord, sans être exactes. Les mentions affichent le modèle ou l'identifiant (l'appli ne connaît pas les noms), les vignettes de lien de Discord ne sont pas montrées, et une syntaxe que l'appli ne reconnaît pas s'affiche telle quelle : Discord, lui, peut l'interpréter.

9. Bon à savoir

  • Brouillon : votre texte et la limite choisie (2000 ou 4000) sont enregistrés automatiquement, une demi-seconde après chaque modification et à la fermeture de la page ; ✓ Brouillon enregistré s'affiche près du compteur. En rouvrant la page, vous les retrouvez. Il n'y a qu'un brouillon : pour commencer un autre texte, effacez le texte. Le brouillon reste dans ce navigateur, sur cet ordinateur, et rien n'est envoyé ailleurs ; il disparaît si vous effacez les données de navigation, ou à la fermeture d'une fenêtre de navigation privée.
  • Lignes vides au début ou à la fin : Discord les supprime à l'envoi (et refuse un message trop long qui commence par des lignes vides). L'appli ne les écrit donc pas à droite, et le compteur compte exactement ce qui part.
  • Ligne vide dans une citation : possible au début ou au milieu d'une citation, tant que du texte cité suit (à gauche : placez le curseur au début d'une ligne citée et appuyez sur Entrée). Une ligne vide citée en dernière ligne devient une ligne vide ordinaire.
  • Sous-texte dans une liste : Discord ne l'applique pas si une ligne stylée se trouve juste au-dessus ; le bouton est alors grisé. Une ligne vide au-dessus de la liste règle le problème.
  • Ce que l'appli ne reconnaît pas (lien avec une adresse non cliquable, émoji de serveur…) est gardé tel quel : rien n'est jamais perdu.
  • Les teintes des couleurs à gauche sont très proches de celles de Discord, sans être exactement identiques.
  • Pas encore prévu : la version téléphone.
